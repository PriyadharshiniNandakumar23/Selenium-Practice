# DuckDuckGo Search Automation

## Project Overview
Automated DuckDuckGo search functionality using Selenium WebDriver and Java.

## Technologies Used
- Java
- Selenium WebDriver
- Eclipse IDE
- Chrome Browser

## Automation Concepts
- Browser Launch
- Browser Navigation
- Locators (By.name)
- sendKeys()
- Keyboard Actions (Keys.ENTER)
- Page Title Verification

## Test Scenario
1. Launch Chrome.
2. Open DuckDuckGo.
3. Locate the search box.
4. Enter Selenium WebDriver.
5. Press Enter.
6. Verify the page title.
